# Стеганография в пространственной области (метод PVD)

Программная реализация стеганографического метода **PVD (Pixel Value
Differencing)** для встраивания произвольного сообщения в цветное (RGB)
изображение-контейнер. Метод предложен Wu и Tsai (2003).

## Метод

Изображение обрабатывается по каналам в растровом порядке и разбивается на
непересекающиеся пары соседних пикселей $(P_i, P_{i+1})$. Для каждой пары
вычисляется разность $d = P_i - P_{i+1}$; абсолютное значение $|d|$ попадает в
один из шести фиксированных отрезков, ширина которого задаёт число встраиваемых
в пару битов:

| Отрезок | `[0,7]` | `[8,15]` | `[16,31]` | `[32,63]` | `[64,127]` | `[128,255]` |
|---|---|---|---|---|---|---|
| Бит | 3 | 3 | 4 | 5 | 6 | 7 |

В «гладких» областях (малая разность) встраивается меньше битов, в «текстурных»
(большая разность) — больше, что обеспечивает адаптивную ёмкость при сохранении
визуальной незаметности.

Перед изменением пары выполняется проверка выхода за границы диапазона
(*fall-off-boundary*): если новые значения пикселей выходят за `[0, 255]`, пара
пропускается и биты в неё не встраиваются. Список фактически задействованных пар
возвращается как параметр встраивания и используется при извлечении.

```
stego/
  pvd.py          # ядро метода: embed, extract, estimate_capacity_bits, RANGES
  metrics.py      # PSNR, MSE, RMSE, SSIM, BER, capacity_bpp, NCC
  cli.py          # интерфейс командной строки: embed / extract / capacity
  __main__.py     # точка входа `python -m stego`
```

## Использование

Программа запускается из корня репозитория и поддерживает три подкоманды.

Оценка ёмкости контейнера:

```bash
python -m stego capacity --cover cover.png
```

Встраивание сообщения (на вход — изображение-контейнер и файл сообщения;
на выход — стегоизображение и файл параметров встраивания):

```bash
python -m stego embed --cover cover.png --message msg.bin \
                      --stego stego.png --params params.json
```

При встраивании на стандартный вывод печатаются показатели качества: PSNR, MSE,
RMSE, SSIM и ёмкость (бит/пиксель).

Извлечение сообщения (на вход — стегоизображение и параметры встраивания):

```bash
python -m stego extract --stego stego.png --params params.json \
                        --output recovered.bin
```

## Программный интерфейс

```python
import numpy as np
from PIL import Image
from stego import pvd

cover = np.array(Image.open("cover.png").convert("RGB"), dtype=np.uint8)

stego, params = pvd.embed(cover, b"secret message")
recovered = pvd.extract(stego, params)
assert recovered == b"secret message"
```

- `pvd.embed(cover, message)` → `(stego, EmbedParams)`; бросает `ValueError`,
  если сообщение не помещается в контейнер;
- `pvd.extract(stego, params)` → `bytes`;
- `pvd.estimate_capacity_bits(cover)` → верхняя оценка ёмкости в битах;
- `EmbedParams.to_dict()` / `EmbedParams.from_dict()` — сериализация параметров
  встраивания (используется CLI для сохранения в JSON).

## Ограничения

Метод PVD не является обратимым (исходный контейнер по стегоизображению точно
не восстанавливается) и не обладает робастностью к сжатию с потерями и шуму:
стегоизображение должно передаваться без потерь (PNG, BMP, RAW).
